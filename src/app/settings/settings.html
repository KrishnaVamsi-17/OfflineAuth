Offline TOTP Verification

Provision the single authenticator account used by this device to verify offline login codes.

🔐 How it works:

  • When online, you generate a QR code here and scan it with your authenticator app
  • The shared secret is stored locally on this device for offline verification
  • When offline, users sign in with TOTP or fallback to PIN if TOTP is not set up
  • Only one active TOTP setup is kept on this device at a time
  • Backup codes are still generated for recovery scenarios

⚠️ Important:

  • The current flow does not require a PIN before provisioning the authenticator secret
  • Back up your recovery codes in a safe place
  • Re-running setup replaces the previously stored TOTP secret on this device
